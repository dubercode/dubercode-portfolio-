## About This Portfolio

This project is my interactive engineering portfolio, designed to showcase my professional experience, technical expertise and hands-on implementations.

It is also a practical demonstration of modern frontend development, software engineering practices and automated deployment.

### Main Features

- Interactive professional introduction and terminal.
- Professional experience and technical skills.
- Project showcase with dynamic category filtering.
- Responsive interface for desktop and mobile.
- Animated UI components.
- Direct access to GitHub, YouTube and technical blog.
- Automated deployment through GitHub Actions.
